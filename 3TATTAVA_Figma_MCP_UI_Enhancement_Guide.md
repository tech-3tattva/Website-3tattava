# 3TATTAVA — Website UI Enhancement via Figma MCP
## Complete Execution Guide for Claude Code + Figma Integration

---

## WHAT THIS FILE IS

This is the single execution document for Claude Code (with Figma MCP connected) to transform the 3TATTAVA website from its current state — functional but visually flat and content-heavy — into a premium, engaging, editorially designed experience that feels hand-crafted by a senior engineer, not generated by AI.

**Nothing gets removed.** All existing content stays. The UI presentation, spacing, typography weight, card layouts, hover interactions, scroll animations, image placements, and visual rhythm get upgraded.

### GLOBAL — NAVIGATION

**CURRENT:** Logo centre, nav links below. Search/account/wishlist/cart icons right. "Set pincode" on left. No hover effects on links. Flat dropdown for SHILAJIT RESIN.

**PROBLEM:** No scroll behaviour (stays transparent over content sections where it becomes unreadable). No hover interactions. The dropdown is a basic list, not a branded experience. "Set pincode" clutters the nav.

**FIX:**
```
1. SCROLL BEHAVIOUR:
   On scroll past 80px → nav background transitions from transparent
   to rgba(247,240,226,0.97) with backdrop-filter: blur(20px).
   Logo adapts: white version on dark hero → dark version on scrolled state.
   Transition: 300ms ease.

2. LINK HOVER:
   Each nav link gets an ::after pseudo-element underline.
   Default: scaleX(0), transform-origin: left.
   Hover: scaleX(1), 300ms ease.
   Color: #C8963E. Height: 1.5px. Bottom offset: -4px.
   Active page: permanent underline visible.

3. MEGA MENU (SHILAJIT RESIN dropdown):
   Width: 680px. Background: #1c1304. Padding: 40px.
   3-column grid:
     Col 1: Featured product card (RockResin image + name + price + CTA)
     Col 2: Quick links (Benefits, How to Use, Lab Reports, Compare Formats)
     Col 3: Trust icons (NABL badge SVG, AYUSH badge SVG, Doctor badge SVG)
   Entrance: opacity 0→1, translateY(8px→0), 200ms ease.
   Exit: 150ms delay before closing (prevents flicker on mouse movement).

4. SEARCH:
   Click search icon → input expands inline (width: 0 → 400px, 350ms
   ease-out-spring). Autocomplete dropdown appears at 1 character typed.
   20 pre-built suggestions (Shilajit variants, product names, categories).
```

## FINAL CHECK — WHAT PREMIUM FEELS LIKE

Before considering any section "done," verify against these 8 signals:

```
0. COLOUR ACCURACY: Do the Shahjeet elements use #cd872a (packaging amber)
   and RockResin elements use #C8963E (website gold)? Open both packaging
   label PDFs and verify nothing is swapped. The two products must feel
   visually distinct from each other — same brand family, different character.

1. BREATHING ROOM: Is there enough whitespace? Premium = space between
   elements. If content feels cramped, add padding. Minimum section
   padding: 80px top/bottom on desktop, 48px on mobile.

2. TYPOGRAPHY CONTRAST: Does each section have clear hierarchy?
   At least 3 distinct text sizes visible without scrolling. The eye
   should travel: eyebrow → heading → body naturally.

3. NO IDENTICAL SIBLINGS: Are any two adjacent sections using the same
   layout pattern? If yes, break one of them. Asymmetry = intention.

4. INTERACTION FEEDBACK: Does every clickable element respond to hover
   within 100ms? Buttons, links, cards — everything needs a hover state.

5. DARK/LIGHT RHYTHM: Does the page alternate between dark and light
   backgrounds? Never more than 2 consecutive sections with the same
   background tone.

6. ONE SIGNATURE MOMENT: Does the page have at least one interaction
   that makes the user pause? (Homepage: scroll annotation line.
   Product page: 3D image tilt. Our Story: timeline scroll animation.)

7. LOAD PERFORMANCE: Are images lazy-loaded? Are videos set to
   preload="none"? Is the Archivo font preloaded in the <head>?
   Premium feeling means fast loading, not just good design.
```
